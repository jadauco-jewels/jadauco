# Jadauco — Instagram kit

Ten post templates built on your own product photography.

## Contents

    photos/                    your three product shots, renamed
    TEMPLATES.md               what each template is for and when to use it
    CAPTIONS.md                caption patterns and sample copy
    (open the HTML kit in Omelette to export tiles as PNG)

## Sizes

    Feed          1080 x 1080
    Portrait      1080 x 1350   (more reach — prefer this for product posts)
    Story / reel  1080 x 1920

Safe area: 64px inside the edge on feed posts. On stories keep all type
250px clear of the top and bottom so the interface never covers it.

## Ground colour

Your shoot is on true black, so the templates are black too — the product sits
edge to edge with no visible seam. This differs from the website, which is
cream. Both are correct: cream for the site, black for the feed.

    black    #000000   all photo tiles
    gold     #C6A45C   labels, prices, rules, the mark
    cream    #FFFDF8   headlines
    bone     #F0E6D2   body copy on black

Brass (#8A6A2C) is too dark to read on black. Keep it off these tiles.

## Type

    Alegreya         headlines and product names
    Karla            spec copy
    IBM Plex Mono    labels, prices, buttons

Minimum type size 28px at 1080 wide.

## Logo on posts

Mark only, in gold, in one corner or centred at the foot. Never the full
stacked lockup on a feed post — it competes with the product.

## Rhythm

Three product posts to every one type-led post. The grid should read as
photography with occasional words. Only one gold-filled tile per row.
